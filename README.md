# 🔐 Password Manager

A full-stack Password Manager application that allows users to securely store, manage, update, and delete their website credentials from a simple and responsive interface.

The project is built using **React.js, Node.js, Express.js, MongoDB, and Tailwind CSS**.

---

## 🚀 Features

- 🔐 Store website credentials
- ➕ Add new passwords
- ✏️ Edit existing credentials
- 🗑️ Delete saved passwords
- 👁️ Show/hide passwords
- 📋 Easily manage username and password details
- 💾 Store data in MongoDB
- ⚡ Fast and responsive React interface
- 🎨 Modern UI using Tailwind CSS
- 🔗 REST API using Express.js
